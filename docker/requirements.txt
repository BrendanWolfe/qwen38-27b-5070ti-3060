# flashinfer-python comes in with vllm==0.27.1, but vLLM only USES FlashInfer
# where has_flashinfer() is true, and that wants nvcc on PATH or this package.

# half speed, announcing it in one INFO line (#35) -- which is exactly what
# happened on the reference box, so every DFlash2 number predating 2026-08-26
# was measured on the fallback. cubin publishes up to 0.6.13 against
# flashinfer-python 0.6.16.post3; the launchers export
# FLASHINFER_DISABLE_VERSION_CHECK=1 rather than downgrading either half.

# vLLM and revert the whole patch stack. Only pandas is needed: the extra's other
# members are for HF-hosted --dataset-name values and the plotting subcommands,
# and this repo's scripts use only `random` and `custom`.
pandas==3.0.5
